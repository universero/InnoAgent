# 从零到生产的分阶段学习路线

> 导航：[总目录](../README.md) | [框架选型](01-框架与协议选型.md) | [综合项目](03-综合项目.md)

## 阶段 1：基本闭环

**目标**：理解 Agent 是受控决策和执行循环。

- 学习：[Agent 架构](../01-控制平面/01-Agent架构.md)、[工具协议](../03-执行平面/01-工具调用与协议.md)。
- 实践：手写 ReAct Loop，接入 3 个只读工具和 1 个写工具。
- 验收：Schema、最大步数、超时、错误分类、写操作确认、Trace。

## 阶段 2：知识与上下文

**目标**：构建有证据、可引用、能持续交互的助手。

- 学习：[上下文工程](../02-数据平面/01-上下文工程.md)、[RAG](../02-数据平面/03-RAG与知识工程.md)、[记忆](../02-数据平面/02-记忆系统.md)。
- 实践：带 ACL、引用、拒答和偏好记忆的知识助手。
- 验收：Recall@k、Faithfulness、Citation、不可回答识别、跨用户隔离。

## 阶段 3：复杂任务与状态

**目标**：完成可暂停、恢复和取消的多步骤任务。

- 学习：[规划](../01-控制平面/02-任务规划与推理.md)、[状态管理](../02-数据平面/04-状态管理与持久化.md)、[HITL](../03-执行平面/03-Human-in-the-loop.md)。
- 实践：研究报告、工单处理或发布审批 Agent。
- 验收：Worker 崩溃恢复、幂等、审批过期、状态版本升级。

## 阶段 4：安全执行

**目标**：安全运行代码、浏览器和高权限工具。

- 学习：[沙箱](../03-执行平面/02-沙箱与Computer-Use.md)、[安全治理](../04-保障平面/03-安全权限与治理.md)。
- 实践：代码修复或 Browser Agent。
- 验收：禁网/白名单、短期凭据、测试 Verifier、注入与越权红队。

## 阶段 5：生产治理

**目标**：系统可度量、发布、回滚和运营。

- 学习：[评测](../04-保障平面/01-Agent评测.md)、[可观测性](../04-保障平面/02-可观测性.md)、[运行时](../03-执行平面/04-Agent运行时与平台工程.md)。
- 实践：100+ 回归集、Dashboard、Shadow/Canary、故障演练。
- 验收：质量、成本、P95、安全和恢复均有门禁。

## 阶段 6：规模与优化

**目标**：在成熟基线上降低成本或提升复杂任务能力。

- 学习：[模型路由](../01-控制平面/04-模型路由与推理调度.md)、[多 Agent](../01-控制平面/05-多Agent协作.md)、[训练优化](../04-保障平面/04-训练与持续优化.md)。
- 实践：模型 Cascade、并行专业 Agent、工具能力蒸馏。
- 验收：相对单 Agent/单模型基线有统计显著收益。

## 建议学习节奏

| 周期 | 重点 | 产物 |
|---|---|---|
| 第 1-2 周 | Loop、工具、Schema | 单 Agent Demo |
| 第 3-4 周 | RAG、上下文、记忆 | 知识助手 + 评测集 |
| 第 5-6 周 | 规划、状态、HITL | 可恢复长任务 |
| 第 7-8 周 | 沙箱、安全 | Code/Browser Agent |
| 第 9-10 周 | Eval、Trace、平台 | 发布门禁与 Dashboard |
| 第 11-12 周 | 路由、多 Agent、训练 | 对照实验报告 |

每个阶段都应保留代码、架构图、测试集、Trace 和实验结论，而不只保留演示视频。
