# 实践路线

> [返回总目录](../README.md)

本目录将四个技术平面组合成可执行的学习、选型和上线流程。

## 文档

1. [框架与协议选型](01-框架与协议选型.md)：先选架构，再选技术栈。
2. [分阶段学习路线](02-分阶段学习路线.md)：从单 Agent 到生产平台。
3. [综合实践项目](03-综合项目.md)：知识、研究、代码、多 Agent 和平台项目。
4. [生产就绪检查表](04-生产就绪检查表.md)：上线前逐项审查。
5. [面试题总表](05-面试题总表.md)：跨模块快速复习。
6. [社区面经与真题](06-社区面经与真题.md)：牛客网等公开分享中的真实追问模式。

## 推荐使用方法

1. 先按学习路线完成一个单 Agent 基线。
2. 用综合项目覆盖状态、权限、评测和观测。
3. 使用生产检查表做差距分析。
4. 最后再进行框架替换、多 Agent 或训练优化。
