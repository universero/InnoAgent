# Agent 生产就绪检查表

> 导航：[总目录](../README.md) | [综合项目](03-综合项目.md) | [安全治理](../04-保障平面/03-安全权限与治理.md)

## 架构与状态

- [ ] 已明确确定性路径与模型决策边界。
- [ ] 有成功、失败、取消、超时、预算耗尽和无进展状态。
- [ ] 长任务可持久化、暂停和恢复。
- [ ] 副作用操作支持幂等、对账或补偿。
- [ ] 状态、Prompt、工具和工作流均有版本。

## 工具与权限

- [ ] 参数强类型校验，错误区分可重试性。
- [ ] 每次调用服务端鉴权，不信任模型声明。
- [ ] 高风险动作有审批、审计和短期凭据。
- [ ] Tool Output 被视为不可信输入。
- [ ] 未知执行结果不会盲重试。
- [ ] 敏感写操作由 Runtime 生成稳定 `operation_id`，同 Key 不同参数会拒绝。
- [ ] 重复失败有调用账本、尝试预算、无进展检测和 Circuit Breaker。
- [ ] 大量工具采用权限预过滤、候选检索和按需加载 Schema。

## 大文件与 Artifact

- [ ] 大文件通过 Artifact URI/Handle 传递，不以 Base64 或完整文本进入模型上下文。
- [ ] 读取支持元数据探测、搜索、Range/页/记录游标和总读取预算。
- [ ] 写入支持临时对象、分片/断点上传、Part 校验和与原子发布。
- [ ] 编辑携带 `base_version`/ETag，冲突时不会静默覆盖。
- [ ] Signed URL 短期有效且不会完整记录到 Trace。
- [ ] 文件完成 MIME、恶意软件、DLP、解压限制和派生 ACL 检查。
- [ ] 未完成上传、派生索引和删除传播有生命周期清理任务。

## 上下文、RAG 与记忆

- [ ] 上下文有预算、来源、权限和信任等级。
- [ ] RAG 有检索前 ACL、引用、拒答和新鲜度监控。
- [ ] 记忆有写入策略、冲突、TTL、更正和删除。
- [ ] 原始事件与压缩摘要均可追溯。
- [ ] 跨租户缓存、索引和状态完全隔离。

## 沙箱与安全

- [ ] 不可信代码在隔离环境执行，默认禁网。
- [ ] 凭据短期、最小 Scope、可撤销且不进日志。
- [ ] 已测试直接/间接注入、越权、泄漏和循环。
- [ ] MCP/第三方工具有准入、版本和撤销机制。
- [ ] 有 Kill Switch 和事件响应演练。

## 评测与发布

- [ ] 有组件、轨迹、端到端、安全和恢复测试。
- [ ] 数据集包含真实长尾、不可回答和对抗样本。
- [ ] 发布经过离线回归、Shadow/Canary 和回滚门禁。
- [ ] 高风险切片单独设阈值。
- [ ] 线上失败可进入评测数据闭环。

## 可观测性与成本

- [ ] 每个任务有跨模型、工具、队列和业务系统的 Trace。
- [ ] 记录模型、Prompt、工具、工作流、索引和策略版本。
- [ ] 监控成功率、P95、循环、接管和 Cost per Success。
- [ ] Trace 已脱敏、分权和设置保留期。
- [ ] 成本可按租户、任务和步骤归因。

## 运营与治理

- [ ] 有 Agent、模型、工具、数据源和权限资产清单。
- [ ] 有明确 Owner、SLO、值班和升级路径。
- [ ] 模型/供应商变化有回归和通知流程。
- [ ] 用户可查看关键动作、审批、撤销和数据使用。
- [ ] 定期进行安全红队和灾难恢复演练。
