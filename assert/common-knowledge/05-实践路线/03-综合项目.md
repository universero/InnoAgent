# 综合实践项目

> 导航：[总目录](../README.md) | [学习路线](02-分阶段学习路线.md) | [生产检查表](04-生产就绪检查表.md)

## 项目 A：企业知识与行动助手

### 能力

- 内部知识问答和段落级引用。
- 查询工单、生成变更草稿，提交前审批。
- 用户偏好记忆的查看、更正和删除。
- 部门级 RAG ACL 和工具权限。
- Trace、失败归因、成本与质量 Dashboard。

### 评测

Recall@k、Faithfulness、引用正确率、误执行率、权限泄漏率、Cost per Success。

## 项目 B：持久化研究 Agent

### 能力

- 结构化拆解研究目标和成功标准。
- 并行检索、去重、证据核验和报告生成。
- 暂停、人工改计划、恢复和取消。
- 每个结论绑定来源、时间和证据。
- 预算不足时降级或请求调整。

### 故障测试

搜索超时、来源冲突、Worker 崩溃、审批过期、模型限流、任务跨版本恢复。

## 项目 C：沙箱代码 Agent

### 能力

- 检索代码、生成 Patch、运行测试和静态检查。
- 隔离执行、默认禁网、限制资源。
- 测试结果作为 Verifier。
- 高风险命令审批，所有副作用可审计。
- 输出最小 Diff 和失败诊断。

### 评测

修复率、测试通过率、无关改动率、平均步骤、沙箱违规和成本。

## 项目 D：多 Agent 运营工作台

### 能力

- Supervisor 按技能、权限和负载分配任务。
- Worker 使用结构化消息提交产物和证据。
- 共享任务板支持版本、冲突和重试。
- 单 Agent 失败可替换，不破坏全局状态。
- 与单 Agent 基线对比。

### 评测

任务成功率、并行加速、通信开销、重复工作、冲突率、主管误判和 Cost per Success。

## 项目 E：Agent 平台最小实现

### 平台组件

- Agent/Prompt/Tool Registry。
- Model Gateway 与两级 Cascade。
- Durable Workflow、Queue、Worker。
- State、Artifact、Memory 和 Trace Store。
- Approval Service、Sandbox Pool。
- Eval Runner、Dataset 和发布门禁。

### 验收演练

1. 模型供应商 429 和区域故障。
2. 工具未知执行结果和重复消息。
3. Worker 在副作用后崩溃。
4. Prompt 新版本质量回归并自动回滚。
5. 跨租户读取、间接注入和凭据泄漏攻击。
